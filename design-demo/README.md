# Work Hub 设计 Demo

独立的交互设计预览。直接复用现有任务列表、任务详情、项目页、基础组件和样式，用模拟数据驱动；无需启动 Go 或 Tauri。

在仓库已有依赖的环境中运行：

```sh
cd design-demo
npm run dev
```

打开 http://localhost:4173 。检查和构建：`npm run check`、`npm run build`。产物位于本目录 `dist/`，正式应用构建流程不包含该入口。

## 可调整内容

- 右上角「设计调节」：主题色、圆角、内容密度、最大宽度；自动保存当前浏览器的设计偏好，可恢复默认或复制设计参数。
- 演示状态：混合、全部干净、有改动、目录丢失、检查中、未关联项目、环境未连接。切换状态会重置演示任务。
- 任务列表：搜索、筛选、显示归档、创建任务、进入详情。
- 任务详情：编辑目标、关联项目、按状态筛选、展开目录详情、归档、更换丢失目录、查看模拟改动和 Git 弹窗。
- 项目页：复用现有项目和目录组件，展示关联任务。
- 对话页（`#/sessions`）：复用现有对话列表、消息渲染和输入组件；支持搜索、会话切换、按任务／项目筛选、新建对话、发送模拟消息与停止回复。
- 任务页「查看相关会话」、项目页「相关会话」会进入对应范围的对话；对话头部可查看项目、分支、目录和关联任务，并返回任务页。

数据只存在于页面内存中，刷新后恢复；设计偏好使用独立 localStorage key。编辑器、终端、Git 等系统操作仅显示模拟反馈，不请求生产接口。

对话消息在页面内切换时保留，刷新后恢复初始示例；发送按钮或 Ctrl+Enter 可触发模拟回复，「停止」取消当前回复。新建对话需要选择有可用工作目录的任务。对话回复不调用真实模型。

## 文件位置

- `main.tsx`：Demo 外壳、页面状态、演示交互和调节面板。
- `fixtures.ts`：模拟任务、项目、工作目录。
- `style.css`：仅用于 Demo 的设计变量和覆盖样式。
- `project-preview.tsx`：项目分栏拖动与键盘调整。
- `conversation-preview.tsx`、`conversation.css`：对话页模拟数据、交互适配及局部样式。
- `vite.config.mts`：独立开发与构建配置。

验证记录见 `design-qa.md`。已通过类型检查、独立构建和主要桌面交互检查。

业务组件仍来自 `../frontend/workspace/`，基础视觉来自 `../frontend/styles.css` 与 `../web/`。如果只想试设计，先修改本目录覆盖样式；确认方案后再将调整收敛到正式组件。这里是浏览器交互原型，不是 Figma 设计稿。
